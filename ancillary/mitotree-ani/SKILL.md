# mitotree-ani

> **v1.0.0.** Optional ancillary branch of `mitotree-agent`, run any time after `preflight/mitotree-preflight` (before or after `build/mitotree-builder` / `qc/mitotree-qc`). Wraps `fastANI` (alignment-free ANI calculation) and a Python matplotlib heatmap — no R dependencies needed. Outputs feed into `qc/mitotree-qc`'s ANI section (`parse_ani()` reads `ani/fastani_results.tsv` exactly).

## When to Use This Skill

Use this when you want to:
- Check for duplicate or near-identical mitogenome samples before publishing.
- Detect potential mislabeling (two samples with different names but >99% ANI).
- Visualize pairwise similarity across all samples in a heatmap.

**Do NOT use this skill** if:
- You only have per-gene FASTAs (PCGs/rRNA) without whole mitogenome sequences — ANI requires complete mitogenomes, not just the 13 PCGs + rRNA used by `build/mitotree-builder`.
- You're working in amino-acid (`aa`) mode only — ANI is a nucleotide-level metric.

This branch is **independent of `build/mitotree-builder`** — it can run any time after preflight, even before the build phase finishes, mirroring the original Nextflow DAG's `calculate_ani(mitogenomes.collect())` which ran in parallel with the phylogenomics branch.

## 0. Inputs / Outputs contract

### Inputs

| Path / Arg | Required? | Notes |
| --- | --- | --- |
| `--genome LABEL:FILE` specs (repeatable) | yes, ≥2 samples | Whole mitogenome FASTA per sample — mirror the `--fasta LABEL:FILE` argparse pattern from `build/mitotree-builder/scripts/build_supermatrix.py` for consistency. |
| `--threads N` | no (default: 1) | fastANI parallelization. |
| `--fragLen N` | no (default: 3000) | fastANI fragment length — lower for short mitogenomes (<10kb), but note fastANI's minimum fragment-length requirement. |

### Outputs

| Path | Format | Notes |
| --- | --- | --- |
| `$RUN_DIR/ani/genome_list.txt` | Text | List of input FASTA paths, one per line — built from `--genome` specs. |
| `$RUN_DIR/ani/fastani_results.tsv` | TSV (5 columns, no header) | fastANI native output: query, reference, ani, fragments_mapped, fragments_total — **EXACTLY** what `qc/mitotree-qc/scripts/qc_report.py`'s `parse_ani()` expects. |
| `$RUN_DIR/ani/ani_heatmap.png` | PNG | Hierarchically-clustered heatmap (correlation distance, complete linkage) with ANI values annotated — generated by `plot_ani_heatmap.py` (Python matplotlib, no R needed). |

## 0.5 Ask-User Stop Points

### SP1 — Near-identical samples detected (>99% ANI)

| Trigger | Evidence | Action |
| --- | --- | --- |
| `fastani_results.tsv` contains pairwise ANI >99% between distinct samples | `plot_ani_heatmap.py` or manual inspection | **Surface to user**: "Found N near-identical sample pair(s) (>99% ANI): [(A, B, ANI%), ...]. This could indicate: (a) duplicate/mislabeled samples, (b) genuinely very recently diverged populations. How should I proceed? (A) flag in QC report and continue, (B) remove one sample from each pair and re-run ANI, (C) proceed without flagging" |

**Auto-pick when**: no pairs >99% ANI → no ask needed.

### SP2 — fastANI fails with "no shared fragments" or zero output

| Trigger | Evidence | Action |
| --- | --- | --- |
| `fastani_results.tsv` is empty or contains only header-like lines | fastANI stderr mentions "no shared fragments" or "minFraction" threshold | **Recommend**: mitogenomes may be too divergent for fastANI's default `--minFraction 0.2` threshold, or `--fragLen` is too large for the genome sizes. Ask: "(A) lower --minFraction to 0.1 and re-run, (B) reduce --fragLen to 1000 and re-run, (C) proceed without ANI (skip this branch)" |

**Auto-pick when**: fastANI produces non-empty output → no ask.

### SP3 — Overwrite existing ANI output

| Trigger | Evidence | Action |
| --- | --- | --- |
| `$RUN_DIR/ani/fastani_results.tsv` already exists | A previous ANI run is present | Ask before overwriting: "(A) overwrite, (B) write to a new subdirectory (e.g. `ani_v2/`)" |

**Auto-pick when**: no existing file at that path.

## Procedure

### 1. Build the genome list from `--genome` specs

```bash
run_dir="$RUN_DIR"
mkdir -p "$run_dir/ani"

# Parse --genome specs (LABEL:FILE) into a list file
# Example: --genome "Sample1:mito1.fasta" --genome "Sample2:mito2.fasta"
python3 ancillary/mitotree-ani/scripts/prepare_ani_input.py \
    --genome "Sample1:mito1.fasta" \
    --genome "Sample2:mito2.fasta" \
    -o "$run_dir/ani/genome_list.txt"
```

### 2. Run fastANI

```bash
cd <mitotree-agent-install-path>

pixi run fastANI \
    --ql "$run_dir/ani/genome_list.txt" \
    --rl "$run_dir/ani/genome_list.txt" \
    -o "$run_dir/ani/fastani_results.tsv" \
    -t 4 \
    --fragLen 3000
```

### 3. Generate the heatmap

```bash
python3 ancillary/mitotree-ani/scripts/plot_ani_heatmap.py \
    -i "$run_dir/ani/fastani_results.tsv" \
    -o "$run_dir/ani/ani_heatmap.png"
```

### 4. Handoff to QC

After completion, re-run `qc/mitotree-qc` to fold the ANI section into `qc-report.md`:

```bash
python3 qc/mitotree-qc/scripts/qc_report.py "$run_dir" --output-dir "$run_dir"
```

## Interpretation Guidelines

- **ANI >99% between distinct samples**: likely duplicate/mislabeled, or very recent divergence — always surface to user (SP1).
- **ANI 95-99%**: same species, different populations/strains — expected for conspecific mitogenomes.
- **ANI <95%**: different species — typical for congeneric or deeper splits.
- **Empty output from fastANI**: fragments too short or genomes too divergent — route through SP2.

## Troubleshooting — Signature library

| Signature | Likely cause | Fix |
| --- | --- | --- |
| `fastANI: command not found` | Script invoked outside pixi env | Run via `pixi run fastANI`, or confirm fastANI is in the pixi.toml dependencies (it is). |
| `no shared fragments` / empty output | `--fragLen` too large for genome size, or `--minFraction` threshold too strict | Reduce `--fragLen` (e.g. 1000 for small mitogenomes <10kb), or lower `--minFraction` to 0.1. |
| `parse_ani() KeyError` in qc_report.py | `fastani_results.tsv` format changed (wrong column order) | Ensure fastANI output is 5 columns, no header: query, ref, ani, frag_mapped, frag_total — this is fastANI's native format, don't modify it. |
| Heatmap shows all white/blank | `fastani_results.tsv` has no cross-sample comparisons (only self-self) | Check `genome_list.txt` has ≥2 distinct samples; fastANI needs at least 2 genomes to compare. |
| `matplotlib not found` in `plot_ani_heatmap.py` | matplotlib not in pixi.toml | **Add `matplotlib = "*"` to pixi.toml** — this is a required dependency for the heatmap (see final report). |

## Verification

- [ ] `$RUN_DIR/ani/fastani_results.tsv` exists and has ≥1 row (for N≥2 samples, expect N×N rows including self-self).
- [ ] `$RUN_DIR/ani/ani_heatmap.png` exists and is a valid PNG file.
- [ ] `qc/mitotree-qc/scripts/qc_report.py` successfully parses `fastani_results.tsv` (no KeyError/ValueError).
- [ ] If near-identical pairs exist, they are flagged in `run_summary.txt`'s ANI section.

## What NOT to do

- Do **not** use per-gene FASTAs from `build/01_per_gene/` — ANI requires **whole mitogenome** sequences, not just the 13 PCGs + rRNA. Running fastANI on individual genes will produce meaningless ANI values.
- Do **not** modify the `fastani_results.tsv` format — `qc_report.py`'s `parse_ani()` expects fastANI's native 5-column, no-header format exactly.
- Do **not** skip SP1 when >99% ANI pairs are found — this is often a data-quality issue (duplicate/mislabeled samples) that should be resolved before publishing.

## Handoff

> ANI analysis complete. `ani/fastani_results.tsv` + `ani/ani_heatmap.png` written. <N> near-identical pair(s) detected (>99% ANI): [list if any]. Re-run `qc/mitotree-qc` to fold the ANI section into `qc-report.md`.
